# ASM

![AsmX Logo](.github/avatar.png?raw=true)

See origin code and readme here.([Gitlab](https://gitlab.ow2.org/asm/asm) | [Github Sync Fork(UNOFFICIAL)](https://github.com/OblivRuinDev/AsmX/tree/upstream))

ASMX is a derivative of ASM(https://asm.ow2.io/), which try to solve so problem
such as legacy versions' issues, unnecessary version checks, code responsibility errors, etc.

Unfortunately, this will break some of the API structure,
but we're still working hard to keep the majority of the API available and add more developer friendly APIs.

## Notice
ASMX is just a derivative of ASM and has nothing else to do with it.

## Reporting Issues

If you encounter any issues with the ASMX project, please create a new issue
on the [Github Issue Tracker](https://github.com/OblivRuinDev/AsmX/issues).
